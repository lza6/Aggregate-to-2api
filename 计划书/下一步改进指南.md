## 1. 执行摘要

### 1.1 项目所处阶段

听风AI 已完成 **v9.0.0「智能体 DAG 编排 + LLM 规划器」基础层闭环**：引擎（拓扑排序/并行扇出/fail_fast/重试/状态机）、规划器（Mock 优先 + tryingopen 免费 LLM）、路由（run/plan/查询）真实落地并 E2E 通过。系统当前处于「**单机高并发网关 + agent 能力已有骨架、但 agent 体系尚未产品化闭环**」阶段：

- **护城河**：多提供商聚合网关（5 家上游）+ 号池/代理池 + MAB-EWMA 路由 + SSE 事件流 + 270+ RPS 高并发架构 + 1723 单测全绿 + 覆盖率 83% + CI 全链路门禁。
- **最大的未兑现资产**：DAG 引擎能力已就绪，但**前端没有 DAG 可视化页面、run 只存内存（重启即清）、没有 MCP 对外通道、没有多模态/RAG/自反思深化**——引擎是引擎，产品是产品，中间隔着「把 agent 能力做成用户可感知的产品」这一层。

### 1.2 最值得保留的优势（护城河）

1. **DAG 引擎实现质量高**（`api/agent/dag.py`）：拓扑校验提交时即做（422 中文错误）、skip 判定依赖终态实时完成（非预标记，规避重试竞态）、`background.spawn` 后台执行不崩 worker、`Semaphore` 限流并发、指数退避+抖动重试。这是 v10.0.0 一切深化的地基，**勿重写**。
2. **agent 体系四件套齐备**：`intent`（意图分类）/`critic`（终检）/`memory`（L0-L3 记忆分层）/`guard`（Provider Tier 硬门禁）+ `/v1/agent/*` 端点 + `agent_*` Prometheus 指标。
3. **复用轮子充足**：`vector/{embed,store}`（向量检索）、`cost_forecast`、`sse_events`+`ws_events`、`queue_store`（持久化队列）、`background.spawn`、`providers/registry`——深化层几乎不需要新造轮子。

## 2. 当前项目基线

### 2.1 项目目标与用户

- **目标**：聚合多家上游 AI 图像/对话服务，统一 OpenAI 风格 `/v1/*` 接口；提供生成任务队列、号池/代理池、管理面板。
- **目标用户**：开发者（调用 API）+ 站长/运营（管理面板）+ 公益普通用户（落地页直接生成）。
- **核心使用场景**：文生图/图生图/聊天补全/DAG 多步任务编排。

### 2.2 技术栈

- **后端**：Python 3.11+ / FastAPI / uvicorn / httpx / aiosqlite / pydantic-v2 / prometheus-client / OpenTelemetry（可选）。依赖以 `pyproject.toml:6-17` + `requirements.txt` 为准。

- **外部求解器**：`cf_solver`（Turnstile 求解器，端口 8001），聊天/生图主链路依赖。
- **数据层**：SQLite（aiosqlite）—— `data/imagefree.db`（任务/审计）、`data/account_pool.db`（号池）、`data/email_registry.db`（邮箱池）、`data/edit_leases.db`（图生图互斥租约）。
