# 📁 计划书 — 项目规划与文档中心

> 本目录统一存放项目的**计划、改进指南、审计报告、任务清单**等规划文档，
> 与源代码（`api/`、`frontend/`）完全分离，避免仓库混乱。

## 目录结构

```
计划书/
├── README.md                 # 本索引
├── 审计报告/                  # 代码审计产出（问题清单、严重级别、修复状态）
└── 改进计划/                  # 迭代升级计划（版本路线、步骤分解、TDD 清单）
    └── 下一步改进指南.md       # ★ 主文档：v3.1.0 → v4.0.0 全面改进指南
```

## 文档约定

| 项目 | 约定 |
|------|------|
| 语言 | 全中文（代码/路径保留英文） |
| 更新 | 每次升级迭代后同步更新对应文档 |
| 编号 | 任务按 `C-n`（本轮）/ `S-n`（阶段）编号，全局唯一 |
| 版本 | MAJOR.MINOR.PATCH，见 `下一步改进指南.md` 版本路线 |
