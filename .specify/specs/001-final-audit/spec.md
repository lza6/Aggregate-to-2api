# 终局审计规范：IMP-11 缓存持久化 + 全链路补位

## 问题陈述

当前项目已完成 IMP-01~30 核心功能，但存在以下问题：
1. 部分功能仅"浅层实现"，未考虑边界情况和异常路径
2. 前后端衔接存在断裂点
3. 配置项未完全文档化
4. 测试覆盖存在盲区
5. 文档与真实行为不一致
6. 缺少对新加入者的"保姆级"指引

## 验收标准

### S1: 缓存持久化（IMP-11）完整闭环
- [ ] set 时同步写入 DB 缓冲区
- [ ] 后台 reaper 每 5 轮 flush 一次
- [ ] stop 时全量 flush
- [ ] start 时从 DB 恢复
- [ ] invalidate 同步删除 DB 条目
- [ ] LRU 淘汰项也持久化
- [ ] 10 个测试全部通过

### S2: 全链路审计完成
- [ ] API 契约审查（请求/响应/错误码一致性）
- [ ] 数据库层审查（索引、约束、迁移、兼容性）
- [ ] Worker 引擎审查（竞态、重试、超时、资源释放）
- [ ] 配置审查（环境变量全覆盖、默认值合理）
- [ ] 安全审查（输入校验、注入、鉴权）
- [ ] 可观测性审查（日志、指标、追踪）
- [ ] 文档审查（README、API、部署、排障）

### S3: 文档与体验闭环
- [ ] README.md 与真实行为一致
- [ ] .env.example 覆盖所有配置项
- [ ] SOP 文档完整可执行
- [ ] 新用户按文档可一次跑通

### S4: 项目架构资产
- [ ] 架构 ADR 文档
- [ ] 项目 skills 技能包
- [ ] 验证记录
