1. 服务说明

本服务提供以下功能：

  • 基于文本描述生成图像（文生图）
  • 基于参考图生成变体（图生图）
  • 基于文本生成短视频（文生视频）
  • 支持多种 AI 模型提供商的路由与调度

本服务通过 HTTP API 方式提供，开发者可根据 API 文档集成到自己的应用中。
