隐私政策

最后更新：2026 年 8 月 22 日

本隐私政策说明 imagefree API（以下简称"本服务"）如何收集、使用、存储和保护您的信息。我们坚持数据收集最小化原则：仅收集提供与维护本服务所必需的最少数据。

1. 我们收集的信息

  • 任务元数据：每次生成任务的模型、状态、耗时等元数据会存储于数据库，用于任务查询与运维排障。
  • 提示词：您提交的提示词（prompt）会随任务记录存储，用于结果关联、问题复现与质量改进。建议不要在提示词中提交敏感个人信息。
  • 访问日志：服务器日志可能包含请求 IP 地址、User-Agent 等基本信息，用于安全防护、限流与故障排查。
  • 生成结果：生成的图片在有效期内可访问，过期后可能被自动清理。建议您及时保存生成结果。

我们不会收集：您的姓名、手机号、身份证件、支付信息等与图像生成功能无关的个人敏感信息。本服务不要求注册账号，不设置用户身份体系。

2. 信息的使用

  • 提供生成能力：将您提交的提示词转发至上游 AI 提供商以完成图像生成。
  • 服务质量保障：统计任务耗时与瓶颈，优化路由与排队策略，排查线上故障。
  • 安全与合规：检测与防范滥用、攻击及违反服务条款的行为。

3. 信息的共享与披露

  • 上游提供商：为实现图像生成，提示词与生成请求将传递给必要的第三方 AI 提供商。我们仅传递完成任务必需的数据。
  • 法定情形：仅在法律法规要求或行政机关依法要求时，我们才会向外部披露信息。
  • 不会出售：我们不会向任何第三方出售您的个人信息。

4. 信息的存储与保存期限

  • 任务记录与生成的图片按既定策略定期清理过期数据。
  • 日志按天滚动轮转，自动清理历史文件。
  • 我们在技术和管理上采取合理的安全措施保护存储数据，但请注意，任何互联网服务都无法保证绝对安全。

5. 未成年人保护

本服务面向成年人，不面向未满 18 周岁的未成年人。若未成年人在未获监护人同意的情况下使用了本服务，监护人可联系我们删除相关记录。

6. 您的权利

  • 查询：您可以通过任务 ID 查询自己提交任务的元数据与结果。
  • 删除：如您希望删除特定生成记录，可通过 API 文档页底部的联系方式联系我们处理。

7. 政策变更

我们可能适时更新本隐私政策。重大变更将通过网站公告等方式通知，更新后的政策自发布之日起生效。

8. 联系我们

如对本隐私政策有任何疑问，可通过 API 文档页底部的联系方式与我们取得联系。
