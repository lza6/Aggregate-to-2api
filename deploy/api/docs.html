01快速开始

生成一张图只需一个 POST 请求。Turnstile 人机验证在服务端自动完成，调用方无需关心。高并发下推荐使用 异步模式。

鉴权：写接口（生成 / 图生图 / 聊天）需携带 Authorization: Bearer <key> 或 X-API-Key: <key> 头（key 由站方提供）。

# 同步生成（等待出图，典型 20~45 秒）
curl -X POST https://YOUR-DOMAIN/v1/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $API_KEY" \
  -d '{"prompt":"a cute orange cat","aspect_ratio":"1:1"}'

# 返回
{
  "id": "sync",
  "status": "completed",
  "image_url": "https://pub-xxx.r2.dev/images/xxx.png",
  "error": null
}

图片托管在 Cloudflare R2，URL 可直接访问或下载。

03生成图片

POST/v1/generate

提交后等待直到出图或失败；高并发下请求会进入有界队列（上限 queue_capacity），队列满返回 429。适合低频、需要立即拿结果的场景。

请求体（application/json）：

字段类型必填说明
promptstring是图像提示词，1–2000 字符
aspect_ratiostring否画幅，默认 1:1，见下方
downloadbool否默认 false；true 时返回图片 base64
modelstring否风格预设模型 id，默认 default，见 模型/风格

支持画幅（实时见 /v1/meta）：

aspect_ratio尺寸
1:11024 × 1024
3:4768 × 1024
4:31024 × 768
9:16576 × 1024
16:91024 × 576

响应（HTTP 200，以 status 判断成功/失败）：

{
  "id": "sync",
  "status": "completed",        // completed | error | queued
  "image_url": "https://pub-...r2.dev/images/xxx.png",
  "image_base64": null,  // download=true 时
  "error": null              // 失败/排队时含原因
}

04异步生成（高并发推荐）

POST/v1/generate/async

请求体与同步一致。立即返回任务信息，适合并发/批量场景：

{
  "id": "b0b712c0-...",
  "status": "pending",   // pending → processing → completed | error
  "image_url": null,
  "error": null
}

用返回的 id 轮询 /v1/tasks/{id}，直到 completed 或 error。

05图生图（AI 照片编辑）

POST/v1/edit

输入一张图（或最多 3 张参考图）+ 编辑指令 → 上游生成变体。任务持久化到 SQLite（type=img，重启不丢），上游排队较慢（约 1~5 分钟），故异步：立即返回 pending，轮询结果。

能力边界（已压力测试确认）：单图上限——上游 image_url 是严格单 URL 字符串，传数组或逗号分隔均失败（最多 1 张输入图）；直连并发=1——上游同出口 IP 同时只能有 1 个编辑任务在途，默认本服务图生图全局串行（双层互斥：进程内锁 + 跨进程文件锁，多实例部署也不撞上游；并发提交自动排队，healthz 的 edit_inflight 观察排队数）。上游并发槽瞬态占用自动重试——孤儿上游任务遗留的 429 task in progress 会等待自愈后重试（默认 30 次×20s ≈ 10 分钟），任务不直接失败。住宅代理池可并行——配置 IF_EDIT_PROXY_FILE（每行一个住宅代理）+ 并行数后，每个任务独立出口 IP 即可并行绕过并发限制（token 与提交绑定同一代理）。多图支持——aifreeforever 支持最多 3 张参考图（images 数组），minimaxh3 支持多张 base64 直传，imagefree 上游只支持单图。

请求体：

字段类型必填说明
imagestring否*输入图（单张，向后兼容）：data:image/png;base64,... 或公开 http(s) URL（拒绝私网/回环，≤4MB）
imagesarray[string]否*输入图数组（最多 3 张），每项为 data URI 格式 data:image/*;base64,...。aifreeforever 和 minimaxh3 支持多图。
promptstring是编辑指令，1–2000 字符
downloadbool否完成后是否同时返回结果图 base64
modelstring否风格预设 id（仅支持 applies_to 含 img2img 的模型）

* 注意：image 和 images 至少提供一个。单图传 image 字段（兼容旧版），多图传 images 数组。

图片上传方式：调用方传 data URI(base64) 或公开 URL → 服务端解码/下载为字节 → 经上游 upload-url 拿 presigned 地址上传到其 R2 对象存储 → 以 R2 publicUrl 直链作为 image_url 交给上游。即字节经本服务中转、落地在上游自己的存储，交给上游的是 R2 直链（不是 base64，也不是调用方原 URL）。

响应 / 查询：

{
  "id": "b0b712c0-...",
  "status": "pending",      // pending → completed | error
  "type": "img",
  "image_url": null
}
# 轮询：
GET /v1/edit/tasks/{id}   → completed 时含 image_url（+ base64 当 download=true）

07错误与状态

HTTP场景说明
200生成完成status: completed，含 image_url
200业务失败status: error，含 error 原因
202仍在排队/生成中同步接口超过等待窗口，响应含 Location 头，GET 该地址查询
429队列已满并发过高被限流，稍后重试
422参数校验非法 aspect_ratio / 空 prompt 等
404任务不存在查询异步任务时

常见 error：turnstile 求解失败（人机验证未通过，可重试）、生成超时、生成失败（上游拒绝该 prompt，多为内容安全拦截）。

🚀 快速开始

以下 curl 示例可直接复制使用，把 YOUR-DOMAIN 替换为实际服务地址。

1. 生成图片（同步）

提交后等待直到出图或失败，适合低频调用。

curl -X POST https://YOUR-DOMAIN/v1/generate \
	    -H "Content-Type: application/json" \
	    -d '{"prompt":"a cute orange cat, soft lighting","aspect_ratio":"1:1"}'

2. 异步生成（高并发推荐）

立即返回 task_id，用 GET /v1/tasks/{id} 轮询结果。

# 提交异步任务
	curl -X POST https://YOUR-DOMAIN/v1/generate/async \
	  -H "Content-Type: application/json" \
	  -d '{"prompt":"a cute orange cat","aspect_ratio":"1:1"}'

	# 轮询结果（返回 completed 后即可取 image_url）
	curl https://YOUR-DOMAIN/v1/tasks/<task_id>

3. 指定模型和分辨率

curl -X POST https://YOUR-DOMAIN/v1/generate/async \
	    -H "Content-Type: application/json" \
	    -d '{
	      "prompt": "cyberpunk city, neon lights",
	      "aspect_ratio": "16:9",
	      "model": "minimaxh3/nano-banana-pro",
	      "resolution": "2K"
	    }'

4. 图生图（AI 照片编辑）

# 图片 data URI 可通过 base64 编码获取
	curl -X POST https://YOUR-DOMAIN/v1/edit \
	  -H "Content-Type: application/json" \
	  -d '{
	    "image": "data:image/png;base64,iVBORw0KGgo...",
	    "prompt": "make it a watercolor painting"
	  }'

	# 轮询结果
	curl https://YOUR-DOMAIN/v1/edit/tasks/<task_id>

5. 查询任务状态

curl https://YOUR-DOMAIN/v1/tasks/b0b712c0-9826-4cb1-8604-d710cc58438a

6. 查询可用模型列表

curl https://YOUR-DOMAIN/v1/models

7. 获取站点信息

curl https://YOUR-DOMAIN/v1/meta
