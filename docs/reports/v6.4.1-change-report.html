关键设计决策

1. 版本号单一来源

之前「代码注释写 v6.3.4 / 前端显示 v4.3.3 / 后端 6.3.0」三处漂移。改为：frontend/package.json 为前端唯一版本源，build-time 经 vite define 注入 __APP_VERSION__；后端 pyproject.toml→api/main.py 与 deploy/docker-compose.yml 镜像 tag 同步到 6.4.1。此后前端版本随构建自动更新，不再需要手改组件。

2. 总用量「主卡」而非拆卡

聊天用量面板把「总量 tokens」提为唯一焦点卡（grid-column:span 2 + 主题色边框 + 大字号），Prompt/Completion/推理收敛为副行（cu-today），调用次数/耗时/工具调用降为次要信息 —— 满足「直接显示总用量」。

3. 移除失控功能

/solar 宇宙星图是早期对需求误读引入，非本服务能力；从路由与导航移除，恢复 e2e-smoke 预期的 8 导航，避免「有页面无能力」的假功能。
