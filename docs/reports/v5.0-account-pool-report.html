1. 升级背景与核心架构

针对原有号池对单源邮箱强依赖、易受 429 频控与封号影响的问题，实施 v5.0 Account Pool 2.0 升级：

  • 多源弹性邮箱抽象 (Mail Provider Strategy)：提供 BaseMailSource 统一接口，实现 LinshiMailSource、MailTmSource、GuerrillaMailSource、CustomImapSource，支持多源打分轮换与自动切源降级。
  • 账号生命周期状态机与自适应延寿 (Account FSM)：支持 unregistered → registering → active → working → cooling → dead 状态流转，401/403 异常熔断，每日自动签到与超期唤醒。
  • 自适应分类退避与断点续跑注册 Worker：CF 阻断退避 30s、邮箱限流退避 60s、IP 污染退避 120s，保障高并发批量注册零死锁、零空转。
