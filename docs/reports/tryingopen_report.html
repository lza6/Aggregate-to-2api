🚀 本次迭代落地核心功能

Deliverables
1

动态模型目录发现机制

不写死模型列表。后端通过定时异步分析 TryingOpen 前端 JS Chunks 提取最新上线模型（如最新的 GLM-5.3 Flash），并内置 13 款坚固静态回退，确保上游更替零代码改动自愈。

2

代理池自动轮换突破单 IP 限流

复用项目成熟的 free_proxy_fetcher，自动聚合 8 个免费代理源并进行毫秒级 TCP 连通性预检，每次对话自动分配健康代理出口，彻底解决单 IP 20次/h 的频控瓶颈。

3

通用工具调用（Tool/Function Calling）模拟

上游无显式函数调用入参时，系统通过注入严格格式化指令引导模型输出结构化 JSON，并由后置提取器自适应解析 Markdown 代码块与参数键名，无缝桥接 OpenAI tool_calls 标准协议。

4

前端 Dashboard 深度整合 & 在线聊天工作台

仪表盘新增 4 项聊天核心指标与模型分布图；新增 /chat 在线工作台（支持思考过程折叠、流式渲染、30条滑动上下文保护、本地历史与 Markdown 导出）。
