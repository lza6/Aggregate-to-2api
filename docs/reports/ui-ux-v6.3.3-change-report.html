1. 任务背景与核心改进概述

针对线上用户与管理员在移动端窄屏交互、长耗时生图等待、限流/鉴权异常以及 WebSocket 断线误判等痛点，开展了系统的 UI/UX 全链路重构与鲁棒性加固：

改进模块痛点与问题解决方案与落地效果
移动端窄屏适配 iPhone SE (375px) 下徽章挤出屏幕、图表溢出 增加 @media (max-width: 375px) 专属断点，单列卡片展示，图表高度与字号自适应压缩。
渐进式生图感知 出图等待平均 20s+，长时间面对白屏/静态文字 设计 pg-stepper 步进条，实时流转：排队 $\to$ Turnstile 求解 $\to$ 上游渲染 $\to$ 下载分发。
行动化错误提示 上游 429 或 401 报错生硬，无补救措施 智能改写限流为自动故障转移提示；401 错误提供一键复制标准 cURL 命令卡片。
实时日志 WS 韧性 WebSocket 断线无自动恢复与保活，管理员误以为停滞 实现指数退避重连机制（最大 10s）、Spinner 重连动画与 10s 周期心跳指示器。
